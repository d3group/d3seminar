Send from your university account

Run these from the project folder in Terminal. Each command prepares email previews; add --send to deliver after entering your JMU password. No email is sent by the dashboard.

Invite the group
python3 scripts/seminar.py send invite --all
Remind only people with unfinished answers
python3 scripts/seminar.py send remind --all
After choosing “Ask to reconfirm”, contact conditional attendees
python3 scripts/seminar.py send check --all
After finalizing, send the time and calendar file to everyone
python3 scripts/seminar.py send confirm --all

Repeated commands skip messages already sent or attempted. Test mode allows delivery only to your test address.
